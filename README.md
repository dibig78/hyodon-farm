# 효돈농원 직거래 주문 페이지

제주 서귀포 하효동 **효돈농원**의 직거래 주문 홈페이지입니다.
사업자등록·스마트스토어 심사를 기다리는 동안 바로 주문을 받을 수 있도록 만든 원페이지 사이트입니다.

- 사이트: `index.html` (GitHub Pages에서 바로 열립니다)
- 주문 저장: Google 스프레드시트 `효돈농원 직거래 주문 접수`
- 입금 방식: 무통장 입금(계좌 안내) → 농원에서 입금 확인 → 로젠택배 출고

## 폴더 구조

```
index.html            주문 페이지 (HTML·CSS·JS 한 파일)
assets/               홈페이지 사진 (웹용 JPG)
  hero.jpg            메인 사진 (감귤밭)
  tangerine.jpg       노지감귤 사진
  golden.jpg          황금향 사진
  originals/          원본 PNG (필요할 때 다시 편집용)
apps-script/
  Code.gs             주문을 시트에 저장하는 Google Apps Script
  README.md           Apps Script 배포 순서
.nojekyll             GitHub Pages 설정 파일
```

## 1. 상품과 가격 (모두 택배비 포함)

| 상품 | 중량 | 가격 |
| --- | --- | --- |
| 노지감귤 가정용 | 10kg | 21,000원 |
| 노지감귤 선물용 | 10kg | 38,000원 |
| 황금향 혼합 (크고 작은 것) | 5kg | 25,000원 |
| 황금향 선물용 | 5kg | 30,000원 |

가격을 바꾸려면 `index.html` 안의 `CONFIG.PRODUCTS` 배열에서 `price` 값만 고치면 됩니다.

## 2. 설정 — `index.html` 맨 아래 `CONFIG`

```js
const CONFIG = {
  APPS_SCRIPT_URL: "",          // ← Apps Script 배포 후 나온 /exec 주소를 넣습니다
  BANK_INFO: {
    bank: "확인 후 입력",        // 예: "농협"
    account: "확인 후 입력",     // 예: "302-1234-5678-91"
    holder: "확인 후 입력"       // 예: "김동우"
  },
  FARM: { ... },
  PRODUCTS: [ ... ]
};
```

- **`APPS_SCRIPT_URL`이 비어 있으면** 주문은 시트에 저장되지 않고, 주문 완료 화면에 “주문 내역을 복사해서 문자로 보내주세요” 안내가 나옵니다. 페이지 위쪽에도 준비 중 안내 띠가 표시됩니다.
- **`BANK_INFO`가 비어 있으면** 완료 화면에 “입금 계좌는 문자로 안내드립니다”가 표시됩니다. 계좌를 채우면 계좌·예금주와 **계좌번호 복사** 버튼이 나타납니다.
- 두 값을 채우면 안내 띠가 사라지고 주문이 자동으로 시트에 쌓입니다.

## 4. 사진 바꾸기

`assets/`의 `hero.jpg`, `tangerine.jpg`, `golden.jpg`를 같은 이름으로 덮어쓰면 바로 반영됩니다.
실제 농장 사진을 쓰면 신뢰가 훨씬 올라갑니다. 권장 크기: 가로 1400px, JPG 품질 80% 정도.

## 7. 관리자 페이지 (`admin.html`)

주문 확인·입금 확인·송장번호 관리를 하는 농원 전용 페이지입니다. 홈페이지에는 링크를 두지 않고, 손님에게는 주소를 공유하지 않습니다.

- 주소: https://dibig78.github.io/hyodon-farm/admin.html
- 기능: 주문 현황 대시보드(전체·오늘·미입금·미출고, 상품별 매출), 검색·기간·상품·정렬, 일괄 입금확인·삭제, 주문요약·주소 복사, 배송문자 보내기, CSV 내보내기, 출고 명단 인쇄, 자동 새로고침
- 연결: 관리자용 Apps Script 웹앱 URL(`/exec`)과 관리자 키(`ADMIN_KEY`)를 한 번 입력하면 기기에 저장됩니다.
- 관리자 키는 `apps-script/Code.gs`의 `ADMIN_KEY`와 같은 값이어야 합니다. GitHub에는 빈칸으로 두고, Apps Script 편집기에서만 설정합니다.

## 6. 주의할 점

- 이 페이지는 **사업자등록 전 개인 거래**용입니다. 사업자등록·통신판매업 신고가 끝나면 사업자 정보(등록번호, 통신판매업 신고번호)를 footer에 추가하세요.
- 손님 개인정보(이름·연락처·주소)가 시트에 쌓입니다. 시트 공유는 **본인 계정으로만** 두고, 외부에 링크를 공개하지 마세요.
- 주문 완료 화면의 계좌 정보는 누구나 볼 수 있는 공개 페이지에 들어갑니다. 계좌번호 공개가 괜찮은지 확인하고 넣으세요.
